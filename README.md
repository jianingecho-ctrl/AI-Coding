# 职场小判官·甄嬛传版 · 0.9.0

本文件夹是独立甄嬛传版，直接双击「启动甄嬛传版.command」，或依次执行 npm ci、npm run build、npm start。

本版人物、联系人、消息、统计、素材与 AI 密钥使用独立目录；没有主题切换，也不会影响另一版。0.9.0 支持本机识别可见飞书通知，默认人工确认，回复可复制后手动发送，真实通知不调用外部 AI。Mac 首次构建需要 Apple 开发工具和 macOS 15.2+ SDK。详细步骤见 [飞书通知使用教程](docs/飞书通知使用教程.md) 和 [独立版使用指南](docs/独立版使用指南.md)。

在 Mac 上运行 npm run pack:mac 会生成本版专用 DMG/ZIP，应用名称与 Bundle ID 独立，可与另一版一起安装。
