# 职场小判官·海洋版 · 0.10.0

本文件夹是独立海洋版，直接双击「启动海洋版.command」，或依次执行 npm ci、npm run build、npm start。

本版人物、联系人、消息、统计、素材与 AI 密钥使用独立目录；没有主题切换，也不会影响另一版。0.10.0 支持本机识别可见通知并自动进场、联系人优先级队列、嫁给ta和飞踢ta。婚礼音乐可导入本地音频，只播放开头最多10秒。回复可复制后手动发送，真实通知不调用外部 AI。Mac 首次构建需要 Apple 开发工具和 macOS 15.2+ SDK。详细步骤见 [飞书通知使用教程](docs/飞书通知使用教程.md) 和 [独立版使用指南](docs/独立版使用指南.md)。

在 Mac 上运行 npm run pack:mac 会生成本版专用 DMG/ZIP，应用名称与 Bundle ID 独立，可与另一版一起安装。
