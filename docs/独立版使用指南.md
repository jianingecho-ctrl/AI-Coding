# 主题档案与升级指南 · 0.11.0

0.11.0 将原比奇堡（海洋）和甄嬛传两个应用合并为一个双主题应用。入口为「启动双主题版.command」，在测试面板切换主题，六板块和桌宠同步切换。

## 分档保存

```text
~/Library/Application Support/workplace-little-judge-unified/
├── active-profile.json
├── profiles/
│   ├── ocean/
│   │   ├── judge-state.json
│   │   ├── assets/
│   │   ├── audio/
│   │   └── ai-key.enc
│   └── palace/
│       ├── judge-state.json
│       ├── assets/
│       ├── audio/
│       └── ai-key.enc
└── session/
```

同事名单、通知别名、人物、进场、皮肤、优先级、消息和回复、互动次数、尺寸、音量、素材、音乐、AI 配置和密钥分别保存在对应档案。重复出现同一个联系人 ID 也不会合并两边次数或消息。

原内置人物和卡片只允许在本主题使用。自定义素材读取限定在本档案；缓存也按主题隔离。切换会停止通知服务与音效，丢弃草稿和待展示队列，恢复目标主题待机人物。尚未完成的分析最多写回原档案，不弹进另一主题。

每个主题每次开启监测均需主动点击「开始监测」。未送达草稿、识别预览和展示队列不持久化；已送达消息保存最近 200 条，可从当前主题历史恢复。

## 原独立版升级

首次打开某个档案且没有本地配置时，查找：

```text
~/Library/Application Support/workplace-little-judge-ocean/
~/Library/Application Support/workplace-little-judge-palace/
```

复制对应版有效的 judge-state.json、assets 和 audio。保留原文件，不再持续同步。已有统一版配置不会被旧版覆盖。为避免旧密钥加密身份问题，密钥不复制，迁移后 AI 关闭；可以在本主题重新配置。

如果旧比奇堡资料仍是共享 0.7.0，兼容旧目录 workplace-little-judge/ 和 职场小判官/，仅当配置最后是海洋主题时复制海洋资料。无法确定归属的共享宫廷数据不自动合并；旧目录仍保留。

## 删除和备份

当前主题清空消息历史会清除本主题卡片、队列和草稿，并暂停识别；不会清空另一主题。互动统计和婚礼音乐分别清除。替换音乐仅删除对应档案中的副本，不修改导入原文件。

备份或恢复前退出应用，复制整个 workplace-little-judge-unified 目录。不要把 ocean 覆盖到 palace，或反过来。
