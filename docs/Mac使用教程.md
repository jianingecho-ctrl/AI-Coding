# Mac 使用教程 · 0.11.0 双主题版

## 第一次升级

1. 退出旧版。保留旧文件夹和原来的数据，不要删除。
2. 下载 [双主题源码 ZIP](https://github.com/jianingecho-ctrl/AI-Coding/archive/refs/tags/unified-v0.11.0.zip)，双击解压到「下载」。正常文件夹名是 AI-Coding-unified-v0.11.0。
3. 打开「终端」，粘贴这一行后按回车：

```bash
bash "$HOME/Downloads/AI-Coding-unified-v0.11.0/启动双主题版.command"
```

若文件夹被加上「2」或被移到别处，以实际路径为准。也可以在终端输入 `cd` 加一个空格，把文件夹拖入终端，按回车，然后执行：

```bash
bash ./启动双主题版.command
```

每条命令单独执行，不要输入到正在运行程序的终端中。首次会安装依赖、构建并打开应用，需要等待完成。源码运行需要 Node.js 24 LTS 和 Apple 命令行开发工具；通知识别需要 macOS 15.2+ 及 macOS 15.2+ SDK。此前原生模块已能编译的 Mac 通常可继续使用。

脚本如被系统拦截，使用上述终端 bash 命令启动。原生编译或依赖失败时保留具体错误，勿直接强制升级依赖。

控制台左下角应显示「比奇堡档案 / 0.11.0」或「甄嬛传档案 / 0.11.0」。这版只有一个应用、一个入口，不再分别安装两个新版本。

## 选择主题

进入左侧「测试面板」（甄嬛传主题叫「传话演示」），在顶部选择「比奇堡版」或「甄嬛传版」。

整个控制台、六个板块和桌面人物一起切换。联系人、历史、互动次数、人物配置、素材、婚礼音乐、AI 配置及密钥分别保存。切换会暂停通知监测、清除草稿和桌面卡片、停止音效；要继续识别，请进入当前主题的飞书通知板块重新开始监测。

首次进入某个主题时会复制原独立版的有效资料，旧目录保留。复制只发生一次，旧版和统一版以后不自动同步；建议日常使用统一版。旧 AI 密钥不复制，迁移后 AI 关闭，需要在相应档案重新配置。

## 消息、互动和音乐

消息正文默认展开，长内容可滚动、选择复制。「摘要与待办」和「来源与解析说明」可按需展开。

六个互动按钮在默认尺寸下只占一行。「今日互动次数」默认显示总数或刚才的互动，点开可查看全部次数。

掌嘴是更清脆的「啪」。飞踢播放内置「走你」，人物飞走再回来，不需要额外下载音效。音量与静音在「人物设置／宫廷人物」设置。

婚礼音乐在同一页的「嫁给ta · 前奏音乐」导入。选择下载目录中本地已有的 MP3/WAV/M4A/OGG，最大 15 MB；完整文件也可以，只播放开头最多 10 秒。未导入时使用原创钟声，未内置商业歌曲。两主题分别导入，副本和原文件互不影响。

## 以后怎么重新打开

每次运行同一条命令：

```bash
bash "$HOME/Downloads/AI-Coding-unified-v0.11.0/启动双主题版.command"
```

会恢复上次选择的主题。已经打开时再次启动会回到同一个应用。

只关闭控制台窗口不会退出桌宠；点桌宠的「控制台」可重新打开。点「隐藏」只是隐藏人物；控制台「显示桌宠」可恢复。点「退出」或在运行程序的终端按 Control+C 会结束程序。源码运行时保留终端窗口。

## 飞书通知

详见 [飞书通知使用教程](飞书通知使用教程.md)。只处理所选区域中可见的通知，不能读后台聊天或补全截断内容。请把控制台和桌宠移出选区。

已有录屏权限时直接测试。只有程序报告没有权限时，才按系统提示允许当前应用并重新打开；不需要辅助功能或麦克风权限。

## 检查和打包

开发者可在本文件夹执行：

```bash
npm run typecheck
npm test
npm run build
npm start
```

打包：

```bash
npm run pack:mac
```

DMG/ZIP 输出到 release/unified/。把 DMG 中「职场小判官」拖入「应用程序」即可安装。打包包含两套主题和各架构原生识别模块；未签名、公证的开发包需按 macOS 提示在隐私与安全性中允许打开。

云端已运行 Electron 交互及自动测试，未在 Mac 编译原生模块或验证签名安装。真实通知、多屏及扬声器听感需本机验收。

## 数据备份

退出应用后备份：

```text
~/Library/Application Support/workplace-little-judge-unified/
```

profiles/ocean 和 profiles/palace 是两套独立资料。请备份整个目录，不要把一套覆盖到另一套。更多见 [档案与升级指南](独立版使用指南.md)。
