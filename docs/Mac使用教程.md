# Mac 零基础使用教程

## 1. 下载正确版本

下载最新 0.5.1 源码 ZIP，双击解压。先退出旧版小判官。将新解压文件夹放到容易找到的位置，例如桌面。已有旧文件夹可以保留，但这次操作要进入新文件夹。

## 2. 安装 Node.js

如果之前已安装成功，可以跳过。打开 https://nodejs.org/ 下载并安装 Node.js 24 LTS。打开「终端」，输入 `node -v` 和 `npm -v`，都能显示版本即可。

## 3. 进入项目目录

打开「终端」，输入 `cd `（cd 后有一个空格），把新解压的文件夹从 Finder 拖进终端，再按回车。

输入：

```bash
node -p "require('./package.json').version"
```

应显示 `0.5.1`。如果显示旧版本，回到上一步进入新文件夹。

## 4. 第一次安装并启动

依次复制以下命令，每行按回车：

```bash
ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" npm ci
npm run build
npm start
```

安装可能需要几分钟。`warn deprecated` 是依赖提示；如果出现 `npm error`，保留完整错误信息用于排查。正常启动会看到桌面人物和「职场小判官」控制台，左下角显示 `0.5.1`。

也可以双击 `启动职场小判官.command`。如果脚本无法打开，在已进入项目目录的终端执行：

```bash
bash ./启动职场小判官.command
```

## 5. 体验消息与人物

1. 在「测试面板」选择一个联系人，输入模拟飞书消息，点击「发送并触发动画」。
2. 默认七位联系人展示 Word 文件里的七张人物，身体姿势保持原图，进场方式不同。抱膝鱼不会下跪。
3. 点击「查看原消息」核对摘要；点击「回复消息」输入并发送本地模拟回复；点击「肘击」播放趣味特效；点击「忽略」恢复待机。
4. 忽略后点击桌面上的「重新查看 · 联系人姓名」重新打开卡片，也可在历史中点击「恢复到桌面」。恢复不会生成重复历史。
5. 在「联系人」点击姓名，修改人物、进场、皮肤、时长和台词；先「播放桌面预览」，再「保存个性效果」。个人设置覆盖类别默认。
6. 在「人物设置」上传图片/GIF/多图序列帧，再在待机或联系人设置中选择它，保存后才会替换桌面人物。
7. 拖动人物或顶部「拖动小判官」移动窗口。点击「隐藏」后，从控制台的「显示桌宠」恢复。关闭控制台窗口不会退出桌宠；点击桌宠的「退出」才会退出应用。

没有 API Key 时使用明确标记的本地规则解析。此版本不会登录真实飞书，也不会给同事实际发送任何消息。

## 6. 每次打开

在同一项目目录运行：

```bash
npm start
```

也可以双击启动脚本。源码运行时保留终端打开；按 Control+C 会停止应用。更新源码后请重新执行安装和构建步骤。

## 7. 打包为可双击的 Mac 应用

在终端中进入项目目录，执行：

```bash
npm run pack:mac
```

等待完成后打开 `release` 文件夹。苹果 M 系列芯片选择 arm64，Intel 芯片选择 x64。芯片信息可在苹果菜单 → 关于本机查看。

双击对应 DMG，将「职场小判官.app」拖进「应用程序」。以后从应用程序或启动台直接打开。此开发版尚未签名/公证，系统可能要求到「隐私与安全性」选择「仍要打开」。

云端已验证代码构建与 Electron 交互；DMG 的实际打包、安装和 macOS 桌面表现需要在你的 Mac 上验收。
