# Mac 零基础使用教程 · 0.9.0

## 1. 下载独立版

先退出正在运行的旧版本：点击旧应用的「退出」，或在它运行的终端按 Control+C。保留旧文件夹，别把新文件覆盖进去。

选择版本，下载后双击 ZIP 解压到新文件夹：

- [海洋独立版 0.9.0](https://github.com/jianingecho-ctrl/AI-Coding/archive/refs/tags/ocean-v0.9.0.zip)
- [甄嬛传独立版 0.9.0](https://github.com/jianingecho-ctrl/AI-Coding/archive/refs/tags/palace-v0.9.0.zip)

两版可以都下载，分别放在两个文件夹。这是源码 ZIP，需要下面的启动步骤。

## 2. 确认 Node.js

之前已安装且能运行，可以跳过。否则在 https://nodejs.org/ 安装 Node.js 24 LTS。打开「终端」，输入 node -v 和 npm -v，能显示版本即可。

## 3. 双击本版脚本

- 海洋文件夹：双击「启动海洋版.command」。
- 甄嬛传文件夹：双击「启动甄嬛传版.command」。

脚本检查依赖、安装、构建并打开本版，第一次可能需要几分钟。之后每次双击同一文件夹内的脚本。

如果双击打不开，在终端输入 cd 后加一个空格，把新文件夹从 Finder 拖进终端，按回车。根据当前版本执行其中一条：

```bash
bash ./启动海洋版.command
```

或：

```bash
bash ./启动甄嬛传版.command
```

两版没有主题切换按钮。海洋包不能用旧主题参数变成甄嬛包。

## 4. 手动安装与启动

也可以在新文件夹的终端依次执行，每行按回车：

```bash
ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" npm ci
npm run build
npm start
```

镜像地址要复制纯文本 URL，不包含 Markdown 方括号。warn deprecated 是提示；出现 npm error 才需要按完整报错排查。如果 npm 提示 Electron 安装脚本未批准，按当前 npm 给出的 install-scripts 指引检查并批准本项目的 Electron 安装脚本，然后重新安装依赖。

打开后确认左下角：

- 蓝色控制台：海洋独立版 / 0.9.0。
- 朱红金色控制台：甄嬛传独立版 / 0.9.0。

如果仍显示「海洋桌宠版 / 0.7.0」，退出旧程序并进入这次新解压文件夹。检查命令：

```bash
node -p "require('./package.json').version"
cat edition.json
```

应分别显示 0.9.0 和本版标识 ocean 或 palace。

## 5. 体验流程

1. 海洋版「测试面板」、甄嬛版「传话演示」选择联系人、输入模拟消息、发送。
2. 点击「一键播放七类人物」观看本版七人和进场；演示不写历史、不调用 AI、不计数。
3. 卡片支持原文、本地回复、肘击、扇嘴、烧心、比心、忽略、关闭。四种互动有对应图标和音效，次数显示在卡片下方。回复未发送到飞书。
4. 海洋版「联系人」、甄嬛版「宫中名册」编辑姓名与个性效果。只提供本版人物；先播放预览，再保存。
5. 海洋版「人物设置」、甄嬛版「宫廷人物」调整尺寸、声音、待机角色和素材。上传后需在联系人或待机设置中选中并保存。
6. 海洋版「互动统计」、甄嬛版「互动战绩」看今日汇总。清空统计仅影响本版，和消息历史分别清除。
7. 拖动人物或顶部拖动区移动；隐藏后从控制台恢复。关闭控制台不退出桌宠，需点本版「退出」。

默认不需要 API Key，明确标记本地规则解析。此版本不登录飞书，新增可见通知本机识别；先按 [飞书通知使用教程](飞书通知使用教程.md) 绑定别名并核对一条，再开启监测。需要 macOS 15.2+、对应 Apple 开发工具和当前应用录屏权限，源码与终端权限可能不同。

## 6. 每次打开

双击本版脚本，或在本版文件夹运行 npm start。已经构建过的同一文件夹无需每次重新安装依赖。源码运行时保留终端打开，Control+C 会停止应用。

同时使用两版，分别打开各自脚本；同版重复打开会激活已有窗口。退出一版不会退出另一版。

## 7. 打包安装

在你的 Mac 上分别进入本版文件夹，执行：

```bash
npm run pack:mac
```

海洋输出 release/ocean/，甄嬛输出 release/palace/。苹果 M 系列选 arm64，Intel 选 x64；在苹果菜单 → 关于本机查看芯片。

打开对应 DMG，把「职场小判官·海洋版.app」或「职场小判官·甄嬛传版.app」拖进「应用程序」。可同时安装，以后从应用程序或启动台打开，不需要终端。

开发版未签名/公证；如提示无法验证开发者，确认来源后在系统设置 → 隐私与安全性 → 仍要打开。不要关闭系统安全检查，也不要把源码 ZIP 当安装包。

云端已验证代码、构建、Electron 交互和隔离。通知桌面验收使用虚构 OCR 夹具，实际 Mac 原生编译和通知截图仍需本机验收。Mac 音效、拖动、Keychain、跨桌面和 DMG 安装仍需本机验收。数据目录与旧版迁移条件见 [独立版指南](独立版使用指南.md)。
