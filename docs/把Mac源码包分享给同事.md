# 把 Mac 源码包分享给同事

适用你已经使用的 `AI-Coding-unified-v0.11.0.zip`。它是源码 ZIP，不是双击即可安装的 Mac 应用。把原始源码 ZIP 发给同事即可，不要把本机的 node_modules、联系人、消息历史或 AI 密钥打包进去。

下面这段可以直接转发给同事：

1. 双击解压压缩包，把 `AI-Coding-unified-v0.11.0` 文件夹留在「下载」中。
2. 去 https://nodejs.org/ 安装 Node.js 24 LTS 的 macOS 安装包，按安装向导完成。
3. 打开「终端」，执行 `xcode-select --install`。弹出安装窗口就完成安装；提示已经安装可继续。通知模块编译需要 macOS 15.2+ SDK。
4. 每次复制一行到终端，按回车执行：

```bash
cd "$HOME/Downloads/AI-Coding-unified-v0.11.0"
```

```bash
bash ./启动双主题版.command
```

首次启动会自动安装依赖、构建和打开应用，需要联网下载。运行期间保留终端窗口；在该窗口按 Control+C 会停止程序。以后只需重复这两行命令，不用再安装开发工具。

若文件夹名称带有 `2` 等后缀，或不在下载目录，不要硬套上面的路径。在终端输入 `cd `（后面一个空格），把实际文件夹拖入终端，再按回车，然后执行第二行。

打开后先在测试面板发送模拟消息，确认人物和消息卡片出现。再选择主题、配置自己的联系人。两套主题的联系人、历史和统计分别保存，不会自动拥有发包人的设置。

需要识别飞书通知时，系统须为 macOS 15.2 或更新版本。按应用提示到「系统设置 → 隐私与安全性 → 屏幕与系统音频录制」允许当前程序，退出后重新启动；源码运行通常显示 Electron，终端的权限不一定适用于 Electron。无需辅助功能或麦克风权限。

如果提示「找不到文件」，先检查是否进入解压后的项目文件夹；若启动报错，复制末尾完整错误反馈，不要把终端的 `(base)…$` 提示符一并作为命令输入。

希望同事完全不用终端时，由你在 Mac 源码目录执行 `npm run pack:mac`，把 `release/unified` 中适配其芯片的 DMG 发给他。Apple M 系列用 arm64，Intel 用 x64；当前包尚未签名、公证，按系统提示核对来源后处理。
