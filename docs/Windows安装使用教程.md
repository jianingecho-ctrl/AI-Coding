# Windows 安装使用教程 · 0.12.2 体验版

适用 Windows 10 22H2 / Windows 11 的 Intel、AMD 64 位电脑。暂未制作 Windows ARM64 原生包，不支持 Windows 7/8 或 32 位 Windows。Mac 请继续使用 Mac 版，不能打开这个 EXE。

本版包含比奇堡和甄嬛传两个独立档案、桌宠、模拟消息、联系人、消息卡片、六种互动与音效、本地历史和统计。Windows 通知截图及本机 OCR 为实验适配，需要真实 Windows 验收；不能把代码构建通过理解为已经验证实际飞书通知。

## 下载和安装

1. [下载安装包 WorkJudge-Setup-0.12.2-x64.exe](https://github.com/jianingecho-ctrl/AI-Coding/releases/download/windows-v0.12.2/WorkJudge-Setup-0.12.2-x64.exe)。[版本页面](https://github.com/jianingecho-ctrl/AI-Coding/releases/tag/windows-v0.12.2)同时提供本教程、校验文件和源码。
2. 双击 EXE，按中文向导安装。默认只安装到当前 Windows 用户，无需管理员权限。首次安装不需要 Node.js、npm、Python、Swift 或 Visual Studio。
3. 完成后勾选打开应用，或者双击桌面「职场小判官」快捷方式。以后直接双击快捷方式即可。
4. 若应用已在运行，再次打开快捷方式会显示原来的控制台及桌宠。

当前是未签名的体验包，Windows 可能显示「未知发布者」或 SmartScreen 提示。请核对下载来源及版本，再决定是否允许这个安装包运行；不要关闭杀毒软件或降低整机防护。公司设备如被策略拦截，交由管理员处理。

可选：下载同版本的 `SHA256SUMS.txt`，在 PowerShell 中运行下列命令，将结果与文件中的 64 位哈希值对照。这里只读取文件，不会安装软件。

```powershell
Get-FileHash "$HOME\Downloads\WorkJudge-Setup-0.12.2-x64.exe" -Algorithm SHA256
```

## 先用模拟消息验证

1. 打开控制台的「测试面板」，选择比奇堡或甄嬛传。
2. 选择联系人，输入「请今天18点前核对文件并回复」，点击「发送测试消息」。
3. 检查桌宠是否出现、进场是否播放、卡片正文是否能滚动，展开摘要核对解析内容。未启用在线 AI 时使用明确标注的本机规则。
4. 点击肘击、扇嘴、烧心、比心、嫁给ta、飞踢ta，检查对应效果和声音。飞踢会播放内置原创「走你」，人物飞出再回来。
5. 嫁给ta可在人物设置导入自己的本地音乐，只播放开头最多 10 秒；安装包没有内置商业歌曲。检查系统音量、应用音量和静音开关。
6. 切换主题，六个板块和桌宠同步切换，联系人、历史、统计、素材、音乐和 AI 配置分开。切换后通知识别暂停、旧卡片和队列清空。

人物默认在左下角，避开 Windows 右下角通知。可以拖动人物，在人物设置中调节大小及置顶。隐藏会保留控制台入口；退出请使用应用内的「退出」。关闭控制台窗口不会退出桌宠，也不会自动停止已开始的通知监测。

## 飞书通知识别（实验功能）

使用 Windows 系统自带的 Windows PowerShell 5.1、可见区域截图及 Windows.Media.Ocr。仅识别屏幕上实际显示的文字，不接入飞书账号，不读取聊天或通知数据库，不补全隐藏或被截断的消息。没有屏幕上的通知就无法识别。

1. 在 Windows 的「设置 → 系统 → 通知」中允许飞书显示横幅，在飞书中允许展示发送人及消息预览。关闭勿扰后，用虚构内容测试。
2. Windows 需要简体中文 OCR 语言组件。在「设置 → 时间和语言 → 语言和区域」中检查中文（简体，中国）的语言选项，安装系统提供的基本输入/光学字符识别组件。系统没有提供该组件时请让管理员按系统版本安装；模拟消息不受影响。
3. 在「联系人」中创建该同事，姓名与通知一致。OCR 将 `l/I/1` 混淆时，可在该联系人中填写实际识别到的通知姓名别名。相似姓名建议不会自动合并身份。
4. 打开控制台「飞书通知」，默认选区为主屏幕右下角。先选「5秒后识别」，点击「仅预览，不触发」，把控制台、桌宠移出选区，再让一条新飞书通知出现。
5. 查看本轮原始文字和草稿，核对姓名、正文及来源。Windows OCR 不提供置信度，界面显示「系统未提供评分」，不会假装获得准确率。
6. 草稿可手动选择联系人后点击「确认送达桌宠」，人物应进场；确认无误后再试「识别一次」或「开始监测」。姓名精确唯一匹配、文字位置完整且来源窗口符合要求时，自动送达模式才会触发人物。其他情况留在待确认区。
7. 停止使用时点「暂停识别」。程序重启及主题切换后保持暂停；不会开机自动读取屏幕。

建议先用主屏幕、单显示器测试。混合缩放比例、多屏、自定义飞书通知样式、Windows 通知中心及系统更新可能影响窗口归属和坐标。默认选区未覆盖通知时，可调整选区坐标、宽高；最宽800点、最高1000点。选区里出现控制台或文件名时先移开遮挡，不要直接确认错误内容。

系统通知窗口只能帮助确认来自 Windows 通知界面，不能证明某条通知一定来自飞书。请始终核对来源。未能确定窗口来源时，保留草稿供确认。相同发送人和正文在短时间内可能去重，测试时请更换正文。

脚本只对本次子进程指定 RemoteSigned，不修改系统执行策略、注册表或企业权限。如果企业要求脚本签名或禁止 PowerShell，会报告失败；不要用关闭执行策略、管理员提权等方式绕过。无需授予 Mac 的屏幕录制、辅助功能或麦克风权限。

回复是保存在本地的草稿，可复制后去飞书手动发送。所有趣味互动只在你的电脑播放，不会发给同事。

## 本地数据、更新和卸载

按 `Win+R`，粘贴下面的路径即可打开数据目录：

```text
%APPDATA%\workplace-little-judge-unified
```

`profiles\ocean` 与 `profiles\palace` 分别保存联系人、消息历史、互动统计、上传素材、导入音乐及加密密钥。截图和未送达草稿只保留内存，不保存图片。通知消息始终使用本机规则，不调用外部 AI。模拟消息的外部 AI 默认关闭，启用前界面说明发送的数据范围。

备份前退出应用再复制数据目录；不要将含个人消息、联系人和密钥的目录当安装包发给同事。各人首次安装得到自己的本地档案。Mac 旧数据不会自动传到 Windows；Windows 使用自己的系统凭据加密，不能直接沿用 Mac 密钥。

更新前先退出应用，再运行新安装包。卸载通过「设置 → 应用 → 已安装的应用 → 职场小判官」，只删除安装的程序文件和快捷方式，保留本地数据。需要彻底清除数据时，先备份确认，再退出应用并手动删除上述专属数据目录。

## 源码开发和打包（普通使用者可跳过）

开发电脑安装 Node.js 24 LTS。解压源码，在项目目录运行：

```powershell
npm ci
npm test
npm run build
npm start
```

打包：

```powershell
npm run pack:win
```

输出在 `release\unified\WorkJudge-Setup-0.12.2-x64.exe`。Linux 构建机同样能生成未签名安装器；使用 NSIS 内嵌卸载器，不依赖 Wine。卸载清单由构建后的实际文件生成，只删除交付文件，不递归删除用户选中的整个安装文件夹。
