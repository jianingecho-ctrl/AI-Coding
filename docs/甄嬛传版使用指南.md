# 甄嬛传独立版 · 0.9.2

这是固定宫廷风格的独立应用。控制台采用朱红、鎏金和素纸，包含七位原创 Q 版人物，不使用演员照片。没有主题切换或海洋人物选项，名单、历史、计数、素材独立保存。

下载 [甄嬛传独立源码包](https://github.com/jianingecho-ctrl/AI-Coding/archive/refs/tags/palace-v0.9.2.zip)，退出旧版，解压到新文件夹，双击「启动甄嬛传版.command」。需要 Node.js 24 LTS。

也可在终端进入新文件夹执行：

```bash
ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" npm ci
npm run build
npm start
```

左下角应显示「甄嬛传独立版 / 0.9.2」，侧边栏为「传话演示、飞鸽传书、宫中名册、往来书信、互动战绩、宫廷人物」。如看到海洋版，退出并检查文件夹，海洋包不能用参数切成宫廷包。

## 人物

| --- | --- |

| 沈眉庄型 · 沈眉庄 | 走入 |
| 华妃型 · 华妃 | 缓慢飘入 |
| 敬妃型 · 敬妃 | 翻滚 |

| 皇后宜修型 · 皇后宜修 | 右侧滑入 |
| 甄嬛型 · 甄嬛 | 淡入 |

人物保持轻微待机晃动，以进场区分，不要求下跪。在「宫中名册」改成实际联系人姓名，选择本版人物、进场、皮肤、卡片、时长、台词或自定义素材，个人配置优先。默认待机为甄嬛，在「宫廷人物」修改并保存。

卡片包括素纸便笺、御前批阅、胭脂信笺、加急朱批、鎏金宫廷笺；人物皮肤为原色、暖杏、绛紫、墨色宫装，选择后实际改变配色。

## 消息和互动

「传话演示」发送模拟消息或一键播放七人。卡片展示原文、摘要、待办、截止时间、紧急程度、回复要求、本地模拟回复。

肘击、扇嘴、烧心、比心有对应图标和离线音效。次数显示在桌面卡片下方，「互动战绩」展示今日汇总。重启保留，演示不计数。忽略/关闭恢复小尺寸待机。

「飞鸽传书」可识别屏幕上可见的飞书通知；在宫中名册配置通知姓名别名，确认后触发对应宫廷人物。默认人工确认、重启暂停，真实通知仅本机规则分析。使用步骤见 [飞书通知教程](飞书通知使用教程.md)。

当前不登录真实飞书，回复未发送到飞书，可以复制到飞书手动发送，默认标记本地规则解析。AI 设置和密钥只属于本版。

## 安装和旧数据

在 Mac 执行 npm run pack:mac，在 release/palace/ 打开对应芯片 DMG，把「职场小判官·甄嬛传版.app」拖入应用程序，可与海洋版同时安装。开发版未签名/公证，云端没有生成 Mac 安装包。

甄嬛版从独立新名单开始，不自动读取旧 0.7.0 共享数据。完整运行步骤见 [Mac 教程](Mac使用教程.md)，数据和迁移条件见 [独立版指南](独立版使用指南.md)。
