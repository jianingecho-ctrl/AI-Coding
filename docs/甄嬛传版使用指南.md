# 甄嬛传版 · 0.7.0

这是「职场小判官」的新主题，包含七位原创 Q 版清宫人物。消息仍是模拟数据，不登录飞书。人物、控制台、待机提示、消息卡片、出场台词统一宫廷风，保留四种互动、音效、当天计数和本地模拟回复。

## 打开方式

先退出旧版本，下载并解压最新源码，双击新文件夹中的 `启动甄嬛传版.command`。它会检查 Node/npm、安装依赖、构建，并直接启动甄嬛传主题。需要已安装 Node.js 24 LTS。

如果双击脚本无法打开，在终端输入 `cd `（后面一个空格），将新文件夹拖入终端，按回车，再执行：

```bash
bash ./启动甄嬛传版.command
```

也可手动执行：

```bash
ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" npm ci
npm run build
npm start -- --theme=palace
```

控制台左下角应显示「甄嬛传宫廷版 / 0.7.0」。以后运行 `npm start` 或普通启动脚本，会记住上次选择的主题。启动甄嬛传脚本会切回宫廷主题；已在宫廷主题时会保留你选择的待机角色。

## 人物与联系人

| 原有联系人类型 | 宫廷默认人物 | 默认进场 |
| --- | --- | --- |
| 领导—支配我之人 | 皇上 | 跑步进场 |
| 老实之人 | 沈眉庄 | 正常走入 |
| 厌世之人 | 华妃 | 缓慢飘入 |
| 躺平之人 | 敬妃 | 翻滚进场 |
| 小傻之人 | 安陵容 | 蹦跳进场 |
| 大傻之人 | 皇后宜修 | 从右侧滑入 |
| NPC同事 | 甄嬛 | 淡入 |

1. 点击「一键播放七类人物」，可依次预览七位宫廷人物，不写历史、不调用 AI、不产生互动次数。
2. 在测试面板选择联系人、输入消息并发送，桌面会显示对应人物与鎏金宫廷笺。
3. 在「联系人」为任何人单独选择消息人物、进场、皮肤、卡片、台词和自定义素材，保存后生效。
4. 在「人物设置」选择宫廷待机角色，再点击「保存人物设置」。默认待机人物为甄嬛。

主题切换保留联系人个性设置。如果某人仍显示旧人物，在他的「消息人物」中选「使用类型默认」或直接选择宫廷人物；想统一他的卡片，可将「消息卡片皮肤」选为「鎏金宫廷笺」。

## 互动与计数

卡片中的「肘击、扇嘴、烧心、比心」继续显示手肘、巴掌、火焰和爱心，并有对应音效。在人物设置可调音量或静音。次数按联系人和 Mac 本地日期累计，直接显示在桌面消息卡片下方，在控制台「互动统计」也能查看。关闭卡片后恢复小尺寸待机。

## 切回海洋主题

点击控制台顶部「海洋职场」。联系人、历史、素材库、模拟回复、互动次数、尺寸与声音设置保留。已有历史保留当时的人物、台词和卡片皮肤。

## 验证与安装

已在 Linux 云环境验证代码构建、79 项单元测试和真实 Electron 交互。直接启动的主题参数已验证，Mac 双击脚本、音效听感、拖动、Spaces、Retina 与实际打包安装仍需在 Mac 上验收。

在 Mac 执行 `npm run pack:mac`，在 `release` 中选择对应芯片的 DMG，打开后将应用拖入「应用程序」。开发版未签名/公证。首次进入打包应用时，可从控制台顶部切换甄嬛传主题，之后会保存在本地。更完整的安装步骤见 [Mac 使用教程](Mac使用教程.md)。
