# 飞书通知使用教程 · 0.11.0

本版使用屏幕上可见通知的区域截图和本机中文识别，不登录飞书、不读取聊天数据库、不调用外部 AI。只能获取通知实际展示的姓名和正文；隐藏、遮挡或截断的内容无法补全。

## 下载和重新打开

退出旧应用，下载并解压 [0.11.0 双主题源码 ZIP](https://github.com/jianingecho-ctrl/AI-Coding/archive/refs/tags/unified-v0.11.0.zip)。在终端执行：

```bash
bash "$HOME/Downloads/AI-Coding-unified-v0.11.0/启动双主题版.command"
```

首次需要 Node.js 24 LTS、Apple 命令行工具以及 macOS 15.2+ SDK。详见 [Mac 使用教程](Mac使用教程.md)。在测试面板选择比奇堡或甄嬛传，整套页面和桌宠切换，两套资料分档保存。

旧资料首次复制到相应档案，原目录保留；切换会暂停识别、清除草稿和当前队列，不会把上一套消息带进下一套。重新开始监测只针对当前档案。

## 配置联系人和优先级

在「联系人」（宫廷版为「宫中名册」）编辑同事：

1. 显示姓名可以使用你喜欢的名称。
2. 「通知姓名别名」填写通知中完整的发送人名字，每行一个，保存。群名不是发送人；不要给不同联系人使用同一个别名。
3. 选择本版人物、进场和皮肤，播放预览后保存。
4. 「收到消息的优先级」可选最高、高、普通、低。未设置时领导最高、其他普通；单独配置优先于类别默认。

多条已送达通知按优先级排队，同级先到先展示。高优先级可先出场，原卡片回到队列；正在回复或播放互动时暂停插队，结束后继续。关闭或忽略卡片展示下一条，没有待展示消息时恢复待机。桌面显示排队数量和下一位联系人。队列最多保留 200 条，仅在本次运行中存在，重启后可从历史恢复已保存的消息。

模拟消息、预览和历史恢复是主动操作，会立即展示。

## 自动识别并让人物进场

1. 打开「飞书通知」（宫廷版为「飞鸽传书」）。重启后监测暂停，需要主动开始。
2. 默认开启「匹配明确的通知自动送达桌宠」。旧版首次升级也会开启一次；之后手动关闭会被保留。
3. 让通知在主屏幕右上角保持可见。若选区过大，点「恢复紧凑通知选区」改为 480×240 点；坐标单位为屏幕点，不是 Retina 像素。
4. 选择 5 秒或 10 秒准备时间，点「识别一次」，把控制台和桌宠移出选区，在准备时间内展开通知。已匹配的有效通知直接触发人物，无需再确认。点「仅预览，不触发」则只生成核对草稿。
5. 一次成功后点「开始监测」，每 3 秒检查一次，当前尚未处理的可见通知也会送达。可以最小化控制台。

只有需要权限时，才按系统提示允许当前程序录屏，并退出重新打开。此前终端授权不一定等于 Electron 授权；源码通常显示 Electron，打包后显示本版应用。无需辅助功能或麦克风权限。

自动送达条件：系统通知或飞书弹窗内，有文字位置、姓名唯一精确匹配、正文边界可用且没有混入自身界面。位置明确的精确匹配不再因低 OCR 分数单独被阻止；请核对实际内容。仅有文字而没有位置时，仍需来源明确、置信度至少 90%、卡片分隔明确。系统通知窗口本身不保证来自飞书，请到原应用核对。

来源不明、同名、相似姓名建议、未知联系人、边界截断或自身界面混入时仍进入待确认草稿。核对发送人和正文，点「确认送达桌宠」触发。中文姓名后的 l/I/1 混淆仅给出建议，不自动合并身份；可核对后添加准确的通知别名。

「本轮结果」显示文字行数、消息数、重复数及自动送达数。原始文字若包含桌面文件或控制台，先调整选区和遮挡。连续看到相同内容不会反复进场；短时间内完全相同的两条消息可能被合并，测试时换一条正文。

「暂停识别」停止捕获。「清空草稿并暂停」清除本轮文字和待确认草稿。关闭面板不会停止已开启的监测；退出应用会停止。

## 互动和音乐

消息正文默认展开，摘要与待办可展开。六个互动按钮在默认尺寸下一行显示；今日次数默认折叠，可点开查看。掌嘴声更清脆，飞踢播放内置离线「走你」语音。飞踢使人物飞出画面再返回，消息卡片保留。婚礼效果显示戒指和心动台词。互动只作用于本机，不给同事发消息。

「人物设置／宫廷人物 → 嫁给ta · 前奏音乐」支持导入本地 MP3、WAV、M4A、OGG，最大 15 MB。可以选择完整音频，无需提前剪辑；点击互动或试听只播放开头最多 10 秒，末尾淡出。

如需《今天你要嫁给我》（陶喆／蔡依林版本），请导入你本地已有的音频。应用未内置该歌曲，也不会下载；未导入时使用明确标记的原创婚礼钟声。受保护或无法解码的文件会提示，请换可播放文件。导入文件复制到当前主题的 audio/ 目录，删除或替换副本不影响原文件，也不影响另一主题。音量和静音与其他互动同步。

次数按 Mac 本地日期统计，重启保留，保存最近 90 天。预览不计数，消息历史与互动统计可分别清除。

## 回复和隐私

点「回复消息」保存本地草稿，再「复制回复」，到飞书正确聊天手动粘贴、检查并发送。不会自动给飞书发消息。查看通知内容只能查看已识别部分，完整原文仍需打开飞书。

截图不保存、不上传。未确认草稿最多 20 条，仅存内存；手动或自动送达才写入本版最近 200 条历史。真实通知使用本机规则摘要，不调用外部 AI。模拟消息仍可单独配置 AI 服务，数据范围在界面说明。

清空历史同时清除当前卡片、展示队列、草稿并暂停识别。互动和音乐单独清除。

## 验收和打包

云端验证了代码、构建、本地存储升级、优先级队列、真实 Electron 的自动进场、互动动画、导入音频截取、静音和两版隔离。通知输入使用虚构 OCR 夹具，没有读取 Mac 屏幕。

你的 Mac 仍需验收真实通知 OCR、多屏和遮挡、系统录屏授权、扬声器播放及实际打包安装。新版沿用 0.9.3 原生识别模块。

在本版目录依次执行：

```bash
npm ci
npm run build
npm start
```

打包为 Mac 应用：

```bash
npm run pack:mac
```

输出在 release/unified/。云端未生成已签名、公证的 DMG，详细安装步骤见 [Mac 教程](Mac使用教程.md)。
